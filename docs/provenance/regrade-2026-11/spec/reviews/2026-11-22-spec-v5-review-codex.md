- [blocker] The four Same/Wider cells are sound as sufficient tests if C supplies a joint, claim-preserving object translation, A supplies a Lean instance for **every** print instance, and B supplies a joint implication at each such instance. The rules can assign those cells without that evidence. A7's separate field checks can each pass for an interface whose auxiliary Boolean is required to be both true and false. - [blocker] Narrower gives reverse entailment under exact domain inclusion and joint conclusion weakening. Mixed alone establishes neither direction. Strict Wider or Narrower requires a countermodel to the converse. Over naturals, restricting `∀ n, P(n) ∨ n = 0` to positive n is Narrower by the matrix and equivalent as a sentence. Likewise, `∀ n > 0, P(n) ∧ P(0)` is Mixed against `∀ n, P(n)` and equivalent as a sentence. The extra fact strengthens the conclusion on positive inputs, and specialization at 1 recovers the zero case.
