# v0.5.1 Release

- Prepared: 2026-08-08
- Published: 2026-08-08 to `main`; tag `v0.5.1`
- Publication status: **published** — the `v0.5.1` tag is the canonical
  publication record.

Package version: **0.5.1** (`lakefile.toml`, `CITATION.cff`).

## One-paragraph truth

A maintenance release. The conjecture ledger is empty and now says so. `v0.5.0`
shipped a single conjecture, `CONJ-001`, that entered the ledger already
`WITHDRAWN` and was cited in two guides as the worked example of skipping the
prior-art search its own template requires — a demonstration of the mechanism
rather than a use of it. The mechanism stays, because a precise open question
with no proof is a deliverable here and a contributor who does not write Lean
needs that channel; the specimen and the prose built around it are gone. No
theorem statement, statement-match grade, reviewed bridge status, public API,
or axiom profile changes in this release.

## What changed since v0.5.0

| Area | v0.5.1 |
|---|---|
| Conjecture ledger | `conjectures.yaml` is empty. `CONJ-001` and `AISafetyAtlas/Conjectures/RestrictedNFL.lean` are removed from the active state |
| Reporting | `STATE.md` renders `Open conjectures: 0; none recorded yet` instead of `0 of 0`, which read as a failure state rather than an unused mechanism |
| Conjecture guide | `docs/guide/conjectures.md` 128 → 84 lines: the lifecycle diagram, admission philosophy, prior-art-for-this-mechanism section, and the worked-example paragraph are gone; how a statement is checked without being believed, containment, and the record shape stay |
| Novelty-check rule | `docs/guide/methodology.md` states the obligation without anchoring it to `CONJ-001` |
| Retained evidence | `NC-001` — Mathlib carries finite combinatorial VC dimension and no o-minimal structures, definable families, or infinite-domain VC theory — moves to a restricted no-free-lunch lead in `docs/guide/open-work.md`, which also records that the finite case is settled by Schumacher–Vose–Whitley (2001) and Igel–Toussaint (2004) |
| Generator | The conjecture-checks generator emits the import block only when the ledger is non-empty, and terminates the file with one newline; an empty ledger previously produced a doubled blank line and a `git diff --check` warning on every regeneration |
| Regression harness | `scripts/test_validators.py` seeds its own synthetic conjecture record. Six mutation cases indexed `conjectures[0]` and raised `IndexError` once the ledger emptied |
| Documentation accuracy | The conjecture guide no longer undercounts the issue form's fields; the README no longer describes the ledger as recording open questions only |

## What did not change

- No theorem statement, statement-match grade, or bridge review status.
- No public API. The two Lean files touched — `Conjectures/Checks.lean` and the
  removed `Conjectures/RestrictedNFL.lean` — are structurally off the atlas root
  import, which `scripts/validate_conjectures.py` enforces for the whole
  `AISafetyAtlas.Conjectures.*` namespace.
- No axiom profile: 269 audited declarations remain within
  `{propext, Classical.choice, Quot.sound}`. `CONJ-001`'s statement was a
  `Prop`-valued definition and never entered the audit.

## On `v0.5.0`

`v0.5.0` is left exactly as published. It is an immutable, reproducible snapshot
and it still contains `CONJ-001`, including the withdrawal argument — the
counterexample and the prior art it missed. That record stays reachable through
the tag and the Zenodo deposit for anyone auditing the history. What this
release changes is the active state, not the past.
